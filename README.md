# Tic-Tac-Toe-Game
A Python-based Tic Tac Toe game for two players featuring interactive gameplay, move validation, winner detection, and draw detection through a simple command-line interface.
# 🎮 Tic Tac Toe Game

## 📌 Project Description
Tic Tac Toe is a simple two-player game developed using Python. Players take turns marking X and O on a 3×3 grid. The game checks winning combinations, validates player moves, and identifies draw conditions. It provides an interactive command-line gaming experience.

## 🛠️ Technologies Used
- Python
- Conditional Statements
- Loops
- Functions
- Lists

## ✨ Features
- Two-player gameplay.
- Interactive 3×3 game board.
- Automatic winner detection.
- Invalid move validation.
- Draw detection.
- Simple user interface.

## 🚀 How to Run

1. Clone the repository:
```bash
git clone YOUR_REPOSITORY_URL
```

2. Open the project folder:
```bash
cd Tic-Tac-Toe-Game
```

3. Run the Python file:
```bash
python main.py
```
